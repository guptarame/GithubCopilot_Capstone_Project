User Story: Customer Login & Authentication on My Account Page
Story ID: US-AUTH-002
Epic: User Authentication & Account Management
Module: Customer Login Portal (https://askomdch.com/account/)
Priority: High
Severity: Critical 
________________________________________
User Persona
•	As a registered customer / e-commerce shopper, 
•	I want to securely log into my account using my username/email and password, 
•	So that I can view my dashboard, manage my orders, update my billing/shipping addresses, and review my account details.
________________________________________
Preconditions
1.	The user must have an active internet connection and a supported web browser.
2.	The user must already have a registered account on https://askomdch.com.
3.	The user must be on the My Account login page (https://askomdch.com/account/).
________________________________________
Description
The Login section on the My Account page allows returning customers to authenticate themselves. It includes input fields for a username or email address and password, a "Remember Me" checkbox, a "Log in" submit button, and a password recovery link ("Lost your password?").
________________________________________
Acceptance Criteria
1.	Page UI & Elements:
o	The login form must display input fields for Username or email (id="username") and Password (id="password").
o	A "Remember me" checkbox must be present to persist the user session.
o	A "Log in" button (name="login") must be clearly visible and clickable.
o	A "Lost your password?" link must be displayed, redirecting users to the password reset flow.
2.	Validation & Field Checks:
o	If the user submits the form with empty fields, inline validation error messages must appear (e.g., "Error: Username is required" or "Error: The password field is empty").
3.	Successful Authentication:
o	When a user enters valid credentials and clicks Log in, the system authenticates the user and redirects them to their customer dashboard (My Account home view).
o	A welcome success message (e.g., "Hello [Username] (not [Username]? Log out)") must be displayed.
4.	Failed Authentication:
o	When a user enters invalid credentials (incorrect password or unregistered email/username), the system must display an error notice at the top of the form (e.g., "Error: The password you entered for the username ... is incorrect" or "Invalid username or email").
________________________________________
Test Scenarios
Scenario ID	Scenario Description	Expected Outcome
TS-LOG-001	Verify successful login with valid Username/Email and Password.	User is authenticated successfully and redirected to the customer dashboard with a welcome message.
TS-LOG-002	Verify login attempt with invalid/incorrect password.	Login fails, the user remains on the login page, and an appropriate error message is displayed.
TS-LOG-003	Verify login attempt with an unregistered email/username.	Login fails and an error message is displayed indicating the account does not exist.
TS-LOG-004	Verify login attempt with blank username and password fields.	Form submission is prevented, and validation errors are triggered for both required fields.
TS-LOG-005	Verify functionality of the "Remember me" checkbox.	User session remains active across browser restarts when "Remember me" is checked.
TS-LOG-006	Verify navigation via "Lost your password?" link.	Clicking the link redirects the user to the password reset/recovery page.
