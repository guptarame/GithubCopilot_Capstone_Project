# Templates

Shared document templates may be added here when they are used by more than
one SDLC stage. Repository task prompts live in
[`.github/prompts/`](../.github/prompts/), while agent definitions live in
[`.github/agents/`](../.github/agents/).

Every template should state its required inputs, expected output path, and
whether its values are observed evidence or placeholders. Never put
credentials, tokens, or realistic secret-looking values in a template.
